# A Closer Walk

Originally developed as the final project for my Web Development course at Strayer University, A Closer Walk has continued to grow beyond the classroom into a live ministry website and software development portfolio.

## Live Website

https://acloserwalk.org

## Overview

A Closer Walk is a faith-based educational website designed to encourage spiritual growth through interactive resources, AI-assisted educational content, biblical comic reels, and web-based learning experiences.

## Features

- AI-assisted educational content
- Biblical comic reels
- Interactive web pages
- Faith-Trails educational application
- Responsive website design

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Responsive Web Design
- GitHub Pages
- AI-assisted content creation

## Future Plans

The project continues to evolve with additional educational content, interactive learning tools, and new software development projects.
